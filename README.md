# 🚖 New York Taxi Fare Prediction

A Machine Learning and Deep Learning project for predicting New York City taxi fares using historical taxi trip data.

## Project Overview

This project includes:

- Exploratory Data Analysis (EDA)
- Data Cleaning & Preprocessing
- Feature Engineering
- Linear Regression
- Decision Tree Regressor
- Random Forest Regressor
- Deep Feedforward Neural Network (MLP)
- Model Evaluation & Comparison

## Dataset

- **Dataset:** NYC Taxi Fare Dataset
- **Records Used:** 100,000
- **Target Variable:** `fare_amount`

## Best Model

| Metric | Value |
|---------|------:|
| MAE | 1.175 |
| RMSE | 2.479 |
| R² Score | 0.952 |

**Selected Model:** Random Forest Regressor
